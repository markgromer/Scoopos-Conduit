# MY FIRST AI EMPLOYEE · ONE-PAGE QUICK START
**ScoopOS Bow Wow, October 12 · Bring ChatGPT and ONE repetitive job in mind.**

## The six pieces
1. **Job:** One specific business outcome.
2. **Brain:** Actual services, area, prices, and approved policies.
3. **Steps:** Read → verify → decide → draft → ask approval → confirm.
4. **Tools:** Only apps the user has really connected and checked.
5. **Permission:** No customer sends, CRM edits, or payments without authorization.
6. **Proof:** The source record or file must match the actual answer.

## Do this today
1. Open **[ScoopOS Agent Lab](https://scoopos-agent-lab.markgromer.workers.dev/)** and choose a job.
2. Enter YOUR business details. Put **UNKNOWN** for unsupported pricing, routes, policies or availability.
3. Choose one intended data source. **Selections are not integrations.**
4. Keep the safety checks enabled, then **Copy Agent Instructions**.
5. Open [ChatGPT](https://chatgpt.com/), create a **Project**, paste the instructions in Project settings, and run one small task.
6. **Fastest practice:** [Download fictional leads CSV](https://raw.githubusercontent.com/markgromer/Scoopos-Conduit/main/workshops/2026-10-12-build-an-agent/demo-leads.csv), upload it privately to ChatGPT, and use **Copy first task prompt** in the Lab.
7. Check L-001 has status **New**, consent **Yes**; L-004 opted out; L-005 already booked. No invented prices, no sent messages.
8. Save a copy of `AGENT.md` and **Save my agent blueprint** (`.json`) for next Monday.

## What you actually built
- **Project + fictional CSV:** You have a reusable *manual* AI assistant that analyzes a private file. Not a connected CRM agent.
- **Project/Work + verified connected source:** Your agent can do permitted real work using available tools, subject to your account's access.
- **No source access:** Your configuration is prepared but the task is blocked. Not a failure of the class; it identifies the missing integration.

## Three safety questions
- Which exact record or file did it read?
- Did it admit when facts were unknown?
- Did it ask before anything customer-facing or financially consequential?
