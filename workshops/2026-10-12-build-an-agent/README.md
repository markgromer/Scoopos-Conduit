# ScoopOS Bow Wow — Build Your First Real AI Agent

**Monday, October 12, 2026 · 4 PM Arizona**

**Start here (public interactive builder):** https://scoopos-agent-lab.markgromer.workers.dev/

This is NOT the previous multiple-choice simulation. It is an agent-design and installation lab for a real runtime in your own ChatGPT account, plus a reference standalone code agent in `agent-starter/`.

## Workshop outcome

A member:
1. Selects one accountable job (lead follow-up, inbox, daily ops or customer care).
2. Defines business facts, source-of-truth documents, detailed steps, and success criteria.
3. Identifies connected tools and explicit permission boundaries.
4. Downloads `AGENT.md` with behavior, evidence, boundaries and test prompts.
5. Installs it in a ChatGPT Project, Work, or an eligible Workspace Agent.
6. Performs three ACTUAL tests against available tools or a safe private sample.
7. Optionally runs the independent OpenAI API-based agent starter locally.

**This builder does not execute ChatGPT itself.** The student's ChatGPT account owns the AI runtime, connections and approvals. No form fields or API credentials are submitted to this website.

**No ChatGPT plan is implied:** Projects are widely available, Work requires an eligible plan, Workspace Agents require Business/Enterprise/Edu permissions, and the standalone agent needs an OpenAI API key and API billing. Projects alone are not autonomous background workers. New custom GPT creation on personal ChatGPT accounts is unavailable; custom GPTs are being phased out in favor of plugins.

## Don't pretend
Selecting a desired integration does NOT connect it. Copying a prompt does NOT create an autonomous worker. A scheduled background job, app trigger, Facebook lead webhook, and data sync must each be separately configured and proven.

The earlier Bow Wow simulation has been superseded by this workshop. Contact permission, real customer data privacy, financial operations and system changes always need suitable approvals.
