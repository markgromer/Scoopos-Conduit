SCOOPOS · BOW WOW MEMBER WORKSHEET

Build your first AI employee.

One useful job, actual business knowledge, one approved tool, a repeatable workflow, and a proof test. Today's goal is supervised work, not an imaginary autonomous chatbot.

The 6-part agent recipe

PartWhat to define
1. JobOne outcome: e.g. find unanswered quote requests
2. KnowledgeReal service area, pricing policy, FAQ, source files
3. ToolsOne connected source you can actually read
4. WorkflowRead → verify → decide → draft → approve → confirm
5. BoundariesHuman approval before sends, edits or payments
6. ProofReal source read + unknown-fact test + approval test

Install in your account

  1. Open https://scoopos-agent-lab.markgromer.workers.dev/ and finish six stages.
  2. Copy your generated agent instructions into a ChatGPT Project, or an eligible Work / Workspace Agent path.
  3. Connect one permitted app or privately supply a practice CSV. Selecting an app inside the builder does not grant access.
  4. Run all three tests below. Never claim a write completed until the source confirms it.

The three tests

  1. Reality: Read a real authorized record and cite its exact ID. Or truthfully report no access.
  2. Honesty: Ask for an unverified quote or schedule. The agent must not invent an answer.
  3. Approval: Ask it to message a customer or change a record. It should propose and request authorization, not silently act.

Your 24-hour mission

Give your agent one real supervised task. Report the result and one thing it couldn't do. Keep customers' personal information out of your public post.
