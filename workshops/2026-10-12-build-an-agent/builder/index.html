01 / Mission

What job are you hiring AI to do?

An agent should own one repeatable outcome, not have an impossible job description like "run my entire business." Pick the first job it can prove it does.

Real-world rule: This is the job description, not the agent itself. We will install it in ChatGPT, connect an actual source, and run a test before calling the build complete.
02 / Knowledge

Give your agent business truth.

It can't know your policies by guessing. Give it a name, a business, and a real source of truth. Unknown is an acceptable answer.

You're listing sources here, not connecting them yet. Later add actual reference files privately in ChatGPT.
03 / Workflow

Teach it how to do the job.

This is the difference between a chatbot and an agent: a repeatable decision process with inputs, tools, actions, and proof of completion.

Use concrete verbs: read, compare, verify, draft, propose, log. Don't invent unconnected capabilities.
A scheduled task or incoming lead trigger is an optional later activation step. Writing "monitor all leads" in instructions does not turn on a webhook or background worker.

05 / Trust & Control

Decide what it may do on its own.

A good employee knows the boundaries. Your agent should have a clear scope, visible evidence, and a human review step for consequential actions.

Require approval before sending any customer messageDrafting is permitted. Actually sending email, SMS, or DMs requires your approval and valid contact permission.
Require approval before modifying CRM/lead recordsShow record, previous values, new values, and reason first.
Never take payments, issue refunds, or change billing without approvalEscalate anything involving money or financial risk.
Require source evidence and report failuresEvery claim about a customer or system comes from an actual record, and an attempted action isn't called completed.
Workshop rule: The four default protections are required for the classroom version. We're not teaching new operators to let a bot silently refund customers or text everyone in their CRM.

Your agent blueprint is ready. Now make it real.

Choose where your agent will run. Copy the instructions into your own ChatGPT environment, connect the first permitted source, then complete a real tool test.

Beginner route: Save instructions in a ChatGPT Project → privately add a policy/fictional sample → complete one supervised test → connect a supported app later. That is a working manual assistant, not an automatically running agent. Use Work for actual app actions if available.
