# Troubleshooting and answers

## I only have a phone
Read the lesson and copy the prompts on your phone. Airtable's native CSV import currently requires the web/desktop experience. Use the sample data pasted into ChatGPT for the live session and import later on a computer.

## I don't have a ChatGPT Airtable connector
Totally workable. Download the demo CSV and upload it to ChatGPT if your account supports file uploads. Otherwise copy the five example rows into ChatGPT, or work directly from the spreadsheet. Perform edits yourself.

## ChatGPT says it updated Airtable, but I don't see a change
Treat the update as **not verified**. Open the actual record; check whether it changed. If not, edit it manually. Never report an update as successful just because the chatbot sounds confident.

## It tells me a price that I never supplied
Reject the draft. In BUSINESS-BRAIN.md set pricing to UNKNOWN / needs owner approval. Retry the message and ask for the single missing detail first.

## I downloaded a blank CSV and Airtable has no records
That's intentional. Use the **demo** CSV for class. The blank CSV only supplies column headers.

## My quote was already sent. Can I send an automatic reminder?
Not in this starter kit. Verify the actual history, permission to contact, and any prior stop request first. Draft a human-approved message in your normal channel.

## Does it read Facebook forms, SMS, or Sweep & Go?
No. The manual framework stores leads you enter or import. Connecting external services requires separate integrations, explicit permissions, logging, and testing.

## Should I upload my full client list to this repo?
**No.** Public GitHub is not a private CRM. Never commit customer lists, files containing personal data, passwords, or API keys. Use your private Airtable/CRM and share only what your tools and privacy obligations allow.

## Can I copy this material?
Yes, this workshop package is intended for students to download and customize. No business customer data, proprietary external software, or secrets are included.
